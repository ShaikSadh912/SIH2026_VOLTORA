# ⚡ VOLTRA – Hardware Module

> **Sense • Switch • Detect • Protect**

## 🔧 Hardware Overview

The **VOLTRA Hardware Module** is the physical implementation of the automated high-current protection testing platform.

It integrates **power delivery, load selection, current and voltage sensing, switching, protection, and status indication** into a single test setup.

The hardware enables controlled testing under different load conditions and demonstrates how the system **measures electrical parameters, identifies a threshold-crossing condition, detects a trip, and indicates the resulting status**.
